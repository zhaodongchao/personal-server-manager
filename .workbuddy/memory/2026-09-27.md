## register 入口显隐跟随错误开关（修复）

- **缺陷**：`/auth/mail/enabled` 原只返回 `{enabled}`（SMTP 是否就绪），而 `login.vue` 用 `:show-register="mailEnabled"` —— 只配 SMTP、未开 `PANEL_REGISTER_ENABLED` 时注册按钮照样渲染，点进去发码必报 `1034`
- **修复**：接口改为返回 `{enabled, registerEnabled}`（`AuthService.registerEnabled()` 暴露已有 `@Value` 字段）；composable 派生 `registerAvailable = mailEnabled && registerEnabled`，登录页用它控制注册入口。两个开关缺一不可——没 SMTP 就发不出验证码，注册链路必断在第一步
- **install.sh 补环境**（`scripts/` 与 `documents/` 两份需同步，已 diff 确认一致）：新增 `MAIL_HOST/PORT/USERNAME/PASSWORD/SSL`、`PANEL_MAIL_FROM`、`PANEL_REGISTER_ENABLED`；数值/布尔项在 shell 侧给默认值（`:-465` / `:-true` / `:-false`），**避免 systemd 注入空串导致 Spring 类型转换失败**
- **install.sh 是 heredoc 全量覆盖 service 文件的** → 手写 Environment 一重跑就丢。已在结尾 echo 里提示改用 `systemctl edit serverpanel` 写 override
- api-spec.md 第 11 节同步：`/auth/mail/enabled` 返回契约 + 入口显隐规则表
